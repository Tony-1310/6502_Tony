# 6502_Tony
Description of development and pitfalls of 6502 computer

This describes a project to build a computer similar to  an Apple I/II based on the 65c02 chip and following the videos of Ben Eater (https://eater.net/6502). My project developed past the original Ben version, this happening in an add-on process. While this was a great learning process it resulted in mistakes being made. These could all be corrected but could have been avoided had the process been thought through earlier on.
